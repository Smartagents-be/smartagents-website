Claude Code CLAUDE.md carries project context, style and commands, loaded automatically every session. Per project, or globally in ~/.claude.
Cursor .cursor/rules holds modular .mdc rules with four triggers: always apply, apply intelligently, apply to specific files, apply manually. Split one bloated file into targeted rules.
