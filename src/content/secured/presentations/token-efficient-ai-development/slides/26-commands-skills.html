Package recurring prompts as commands or skills.

GitHub Copilot Prompt files in .github/prompts/*.prompt.md, invoked with /name. Skills in .github/skills, one folder per skill with a SKILL.md, invoked by description.
Claude Code Custom commands have merged into skills, and .claude/commands still works. Commands in .claude/commands, skills in .claude/skills.
Cursor Commands and skills both folded into skills in Cursor 2.4, January 2026, and /migrate-to-skills converts the old ones. Invoke with a slash, or let the agent pick by description.

A command is something you invoke. A skill is something the agent invokes when the description matches the task.
