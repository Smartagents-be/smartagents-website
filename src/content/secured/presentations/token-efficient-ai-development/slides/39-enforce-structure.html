ArchUnit, the original.

forbidden: [{
  name: "domain-pure",
  from: { path: "src/domain" },

}]
dependency-cruiser, or the ESLint boundaries plugin.
.NET ArchitectureTests.cs 
Types.InAssembly(asm)
  .That().ResideInNamespace("Domain")
  .ShouldNot()
  .HaveDependencyOn("Adapters")
NetArchTest, or Roslyn analyzers.

Write the boundary as a rule once, and CI fails the moment code crosses it. The agent reads the failing check and fixes itself, so the structure holds without you policing every diff.
