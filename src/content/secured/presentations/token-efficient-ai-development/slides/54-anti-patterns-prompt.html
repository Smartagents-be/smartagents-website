Where the prompt and the setup leak tokens.

The habit What it costs you
Vague prompts that assume the model shares your context. Just-in-case context: every rule, every edge case, the whole log. Every MCP server enabled, and a CLAUDE.md or AGENTS.md so full that the rules drown each other.
The fix What to do instead
Be specific: name the files, and name the goal. Send the high-signal minimum, and let a hook extract the failing lines. Enable only what this task needs, and keep the instructions lean: detail belongs in skills.
