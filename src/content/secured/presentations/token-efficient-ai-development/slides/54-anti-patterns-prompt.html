Where the prompt & setup leak tokens.

Vague, assumption-laden prompts
→Asking as if the model shares your context forces rounds of clarification. Be specific; name the files and the goal.
“Just-in-case” context and raw logs
→Pasting every rule, edge case and full log buries the signal. Send the high-signal minimum; let a hook extract just the failing lines.
Bloated tool / MCP sets
→Overlapping tools the agent can't choose between add decision friction and load their definitions every call. Enable only what the task needs.
A bloated CLAUDE.md or AGENTS.md
→Too many rules drown the important ones and cost tokens every session. Keep it lean; move detail into skills or scoped rules that load only when needed.

Source: Anthropic, Claude Code best practices (code.claude.com/docs).
