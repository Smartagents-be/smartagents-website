Give a scoped task its own agent.

GitHub Copilot Custom agents in .github/agents/*.agent.md, formerly chat modes. Built in: Ask, Edit, Agent, plus a separate Plan agent.
Claude Code Subagents in .claude/agents, each with its own system prompt, tools and context. Keeps the main context small, and runs tasks in parallel.
Cursor Custom modes and subagents, each with its own tool set, model and instructions, in beta. Built in: Agent, Ask, Plan.

A specialized agent only sees what it needs. Less noise, sharper output.
