Where each tool keeps its config.

GitHub Copilot Personal in Copilot settings. Project in .github/, committed. Org through organization instructions.
Claude Code Personal in ~/.claude/. Project in .claude/ and CLAUDE.md, committed. Org through managed policy.
Cursor Personal in Settings, Rules and ~/.cursor/. Project in .cursor/, committed. Org through team rules.

Personal config follows you across every project. Project config lives in the repo, so it travels with the code and the whole team gets it.
