Connect the agent to external tools and data.

Your database Ask what columns a table has, or run a read-only query, without pasting the schema into the prompt. Postgres or Neon MCP.
GitHub Read a PR or an issue, pull the failing CI log, and open a PR when you are done, all from the editor. GitHub MCP.
The running app Let the agent open the page, click through a flow and read the console error itself. Playwright or Chrome DevTools MCP.

Also part of daily work: live library docs with Context7, production errors with Sentry, tickets in Linear or Jira, design specs in Figma. Two cautions: every server costs context, and external data is untrusted input that can carry prompt injection.
