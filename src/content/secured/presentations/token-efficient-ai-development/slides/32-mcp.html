32Extend

Connect the agent to external tools and data.

Your database

Schema & queries

  • Ask what columns a table has, or run a read-only query, without pasting the schema into the prompt.
  • Postgres / Neon MCP
GitHub

PRs, issues, CI

  • Read a PR or issue, pull the failing CI log, open a PR when done, all from the editor.
  • GitHub MCP
The running app

Drive the browser

  • Let the agent open the page, click through a flow and read the console error itself.
  • Playwright / Chrome DevTools MCP

Also part of daily work: live library docs (Context7), production errors (Sentry), tickets (Linear, Jira), design specs (Figma). Config lives per tool in .vscode/mcp.json, .mcp.json or .cursor/mcp.json.

One open standard gives every agent access to the same tools and data. Two cautions: every server costs context (see the context rot slide), and external data is untrusted input that can carry prompt injection.
