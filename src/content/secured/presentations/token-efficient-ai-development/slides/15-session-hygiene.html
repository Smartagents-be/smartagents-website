15Coding agents

Work per session and compact in time.

One task per session

Start fresh for an unrelated task, for example moving from the login feature to a payment bug. Stay in the same session as long as you keep building on the same context; start over once the agent slows down, rereads files it already knows or contradicts earlier changes.

Compact before the window fills up

Quality drops well before the window is full (see context rot). Claude Code summarizes the conversation automatically as you near the limit; do it yourself too with /compact. Filling to 100% isn't possible: summarizing needs free tokens of its own.

A short, focused session is faster and more accurate than a long, full one. Close and restart as soon as the task changes.
