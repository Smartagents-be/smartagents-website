Configure once, then just ask.

1 · Configure once .mcp.json 
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["mcp-postgres"]
    }
  }
}
Same JSON everywhere. Copilot uses servers, and the path differs per tool: .vscode/, .mcp.json, .cursor/.
2 · Then just ask agent 
> Which columns are on the
  sessions table? Write a query
  for the ones active in the last hour.
⏺ postgres · describe "sessions"
⏺ postgres · query (read-only)
The agent reads the schema itself. You never pasted it.

Instead of pasting the schema, the log or the docs, the agent fetches exactly what it needs: less context, and always current.
