Run scripts automatically on events.

GitHub Copilot Agent hooks in .github/hooks/*.json, run locally, on the same events as the Claude format.
Claude Code Hooks configured in settings.json. Auto-format after an edit, or block a command.
Cursor Hooks in .cursor/hooks.json, per project or per user in ~/.cursor. Observe, block, or inject context.

Similar events, named differently per tool: PascalCase in Claude Code and Copilot, camelCase in Cursor. Automate guardrails instead of typing them every time.
