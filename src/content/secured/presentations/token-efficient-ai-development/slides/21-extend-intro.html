Configure the agent once, reuse it.

Scoping gets the agent started well. Extending it lets every future session build on that foundation without repeating yourself.

02 Commands and skills Package recurring workflows so you or the agent can invoke them.

04 Hooks Automate guardrails on events: format, test, block.
05 MCP Connect the agent to external tools and data.
