Plan before you code.

Ask for the approach first Have the agent outline the steps and the files it will touch before it writes any code. Most tools have a plan or ask mode for exactly this.
Correct in prose, not in diffs Fixing a wrong direction in a 200-token plan is far cheaper than catching it in a 5,000-token diff you have to read, then revert.
Then implement in small steps One change at a time. Smaller diffs mean smaller context, faster review, and a clean point to stop if it goes wrong.

A wrong plan costs a sentence to fix. A wrong implementation costs the whole generation, plus the review, plus the redo.
