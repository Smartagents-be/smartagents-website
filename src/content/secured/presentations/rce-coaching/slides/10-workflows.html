Deterministic workflows

Build as many as you can. Rethink the workload: replace the task with a setup that does it for you.

Instead of the task Set up
Writing the release ticket → A shell script that writes it
Checking for regressions → Integration tests that run on every change
Documenting in Obsidian or Confluence → A template or a script that fills it

Something wrong? Fix the script once, and every run after it is right. A script can be reviewed, shared and tuned to how you work.
