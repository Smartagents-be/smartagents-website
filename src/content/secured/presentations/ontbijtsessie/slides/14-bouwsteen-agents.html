Bouwsteen 04 van 04

Een digitale collega, geen lineaire workflow

Geef een agent een doel, geen stappenplan.

01 Het model beslist Bekijkt de stand van zaken en kiest zelf welke tools nodig zijn, en in welke volgorde.
02 Tools draaien Ze voeren uit wat het model besliste. Het resultaat gaat terug, en het model beslist opnieuw.
03 Klaar Het model bepaalt zelf wanneer het stopt: zodra het geen tool meer nodig heeft.

Eén ronde is één turn. De agent vraagt jou om bevestiging op de grenzen die jij vastlegt.
