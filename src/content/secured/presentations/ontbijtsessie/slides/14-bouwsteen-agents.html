Geef een agent een doel, geen stappenplan. Het model kiest zelf welke tools nodig zijn en in welke volgorde, en stopt zodra het geen tool meer nodig heeft.

Op de grenzen die jij vastlegt, vraagt de agent jou om bevestiging.
