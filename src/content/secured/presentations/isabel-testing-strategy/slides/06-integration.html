What only an integration test finds

The current CloudHSM depends on OpenSSL 1.0, not on 3.0.

Unit test CloudHSM is replaced by a mock
The real library is never loaded OpenSSL is never touched The dependency stays hidden
Integration test The real CloudHSM client, in a test container
The real library is loaded It asks for OpenSSL 1.0, not 3.0 The dependency shows before production
