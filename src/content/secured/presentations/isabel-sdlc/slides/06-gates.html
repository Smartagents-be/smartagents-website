What the quality gates check

Team standards Code standards, agent guidelines and architecture rules per team.
Correctness Unit and integration tests, a coverage threshold, evals in CI, API contract and migration checks, performance budgets and accessibility checks.
Security and compliance Security, dependency and secret scans, no personal data in logs, and four-eyes approval with an audit trail.
Review An AI reviewer checks acceptance criteria, guidelines, bugs, vulnerabilities and performance. Then a person reviews the merge request.

Through MCP the agent reads the ticket, and checks the running app against the spec.
