The hardest constraint is not technical

“We’ve always done it this way” Answered by someone inside the team who shows, on real work, that it can be done differently.
“I don’t trust it. My code is better” Answered by real changes that show the output meets your standards, once the context and the gates are set up well.
“It only creates slop” Answered by gates. Slop is what unchecked output looks like. Most teams have review and CI, but not every team applies them consistently.
