Issues we see today

Belief Nobody trusts the output, and everybody expects miracles. Those are the same mistake made in opposite directions.
Capability No training, and processes built for a world where writing code was the expensive part.
Foundation Code quality is not visible. Code is not gated by quality standards. Most product knowledge lives in people’s heads.
Tooling Nothing is unified, there is no common way of working, and the average developer has too little AI to learn on.
